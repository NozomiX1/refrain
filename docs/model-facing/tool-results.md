## 拒绝和出错

主模型用 Edit、Write 改 `~/.refrain/` 下的文件：

```
~/.refrain/ 下是记忆的存储，由后台自动整理，不能直接修改。如果用户要改某条记忆，先用 read 把当前内容念给他核对，再告诉他"已记下，接下来后台整理时会按你的话更新（一般在几轮对话之内）"。如果用户只是让你记住某件事，不需要写任何文件，后台会从对话里整理。
```

主模型调用 submit：

```
submit 只供后台整理使用，和用户对话时不需要调用，包括用户让你记住或整理记忆的时候。
```

数据库暂时读不到：

```
这次检索没能完成：记忆库暂时读不到（数据库正被占用或出错）。可以先不依赖记忆继续工作，之后需要时再试。如果回答用户需要查以前的记录，就告诉他暂时查不到。
```
