# 0010. 提取深度：原文是唯一事实来源；摘要记录"做过什么"，带标题和标签；跨会话不注入

- 状态：采纳（2026-10-23）；第 4 条被 [ADR-0015](0015-context-assembly.md) 限定：新会话不带以前会话的摘要；压缩时本会话的摘要按预算放入，旧的只留标题或逐出；摘要的归属被 ADR-0015 定为项目级（标明来自哪个会话），检索范围是整个项目；"transcript 被清理后另存"由 [design.md](../design.md) 4.7 落实：出处和裁剪后的文字存在我们的数据库里，transcript 删了也有效
- 日期：2026-10-23
- 相关：[questions.md](../questions.md) B2 · [research/b2-extraction.md](../research/b2-extraction.md) · [ADR-0003](0003-admission.md)（准入）· [ADR-0004](0004-evidence-and-hypotheses.md)（引用链）· [ADR-0009](0009-writer.md)（压缩只拼装）

## 背景

B2 的问题是：从对话里大量提取出条目（mem0 式），还是少提取、多保留原文，需要时再去检索。

逐层对照之前的 ADR 后发现，长期知识和现状其实已经有答案了：

- 长期知识的写入门槛很严，宁缺毋滥（ADR-0003），而且每条都附原话引用（ADR-0004），本身就是"少提取"。
- 现状只是一份小快照（ADR-0008）。

所以 B2 真正要定的只有"发生了什么"这一层：摘要写多细，要不要保留原文。

## 考虑过的选项

1. 重度提取：原文提取成条目以后，就不再依赖原文。
2. **原文为主，摘要为辅**（选这个）。
3. 只存原文，不做摘要。这样压缩时没有现成的东西可以拼，和 ADR-0009 冲突。

## 决定

**1. 原文是唯一的事实来源，必须保留。** 长期知识的引用链（ADR-0004）最终指回原文。

**2. 摘要记录"发生了什么"，让将来知道做过什么。** 每段摘要带标题和标签，方便以后检索。摘要有两个用途：

- 回顾：将来想知道"做过什么、怎么讨论的"，先看摘要；需要细节时，再按摘要指的位置去读原文。
- 压缩：ADR-0009 中压缩时拼进去的"已处理部分的摘要"，就是它。

**3. 摘要和长期知识，由 worker 在同一次运行里写出。** 这沿用 ADR-0009：只有 worker 写，现状也在同一次运行里更新。

**4. 摘要跨会话不主动注入，只供检索。** 会话开始时只注入长期知识和现状，细节在 C1 定。

**5. 第一版直接引用 CC 自己的 transcript，不另存一份。** 原文要不要另存、要不要脱敏，留给 F 段。

**这次不定的：**
- 检索怎么做（用 grep 还是语义搜索，由主模型搜还是交给子 agent），新增为 C6。
- 摘要写多细、标签怎么定，留给实验（E6）。现在不做实验，因为结构上的选择不需要实验来定：原文本来就由 CC 保存，留着几乎没有成本。真正需要测的只有摘要粒度，而这要等 worker 能跑起来才测得了。

## 理由

- **问细节必须靠原文。** 在 LongMemEval-V2 上，去掉原文后，细节题的准确率从 66% 掉到 29%。标注实验里我问"…来着？"，问的全是细节：过去的 bug、测过什么、当初怎么讨论的、某个具体数字。
- **问流程，提炼有帮助。** 同一篇论文里，去掉笔记后，流程题的准确率会下降。我们需要提炼的部分，由长期知识和摘要来承担。
- **"原文加说明，让 coding agent 去搜"表现最好：** 72.5%，而最好的 RAG 只有 48.5%。CC 的主模型本身就是 coding agent。摘要和标签就相当于那份"说明"，告诉搜索的人去哪里找。
- **trace-memory 的结构和这里一致：** 原文、话题切片、知识三层；切片跨会话不注入，只供检索。

## 后果

好的方面：
- 不会因为提取时漏掉了，就永久丢失。原文一直都在。
- 摘要一份写出来，回顾和压缩都能用。

要付出的代价和风险：
- **原文里有密码。** 长期知识和现状靠写入时过滤来守住 F3（"密码绝不进入记忆"）；但搜索原文时，密码可能会进入上下文。这个留给 F3。
- **CC 的 transcript 默认 30 天就会被清理。** 我已经改成了 365 天，但成品不能指望每个用户都去改。另存的方案留给 F 段。
- **依赖 CC transcript 的格式。** 格式一变，引用链就会断。

## 什么情况下推翻

- 实验发现，按摘要定位、再读原文的方式，经常找不到东西 → 加重摘要，或者引入语义检索。
- CC transcript 的格式或者保留策略变了，导致引用链断掉 → 由插件另存原文。
