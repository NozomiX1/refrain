# 架构决策记录（ADR）

一个决策一个文件，按编号排序。规矩只有两条：

1. **固定格式**：背景 → 考虑过的选项 → 决定 → 理由 → 后果 → 什么情况下推翻。
2. **只追加，不改写**：决策变了，就新写一份 ADR，在里面注明"取代 000X"，再把旧 ADR 的状态改成"已被 000Y 取代"。除了状态这一行，旧 ADR 的正文一律不改。

状态：提议 · 采纳 · 已被取代 · 废弃

值得写 ADR 的决策：难以回头的、真有备选方案的、将来会被问"为什么"的。
